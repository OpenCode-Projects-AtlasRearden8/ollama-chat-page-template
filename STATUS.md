# STATUS — ollama-chat-page-template

Updated: 2026-11-01

## What was built

A zero-install, single-file chat playground template for any OpenAI-compatible endpoint
(defaults to Ollama). From scratch in this folder this release contains:

- **`index.html`** — the whole app in one file (main "midnight" theme):
  - Settings drawer: editable base URL (auto-normalized to `http://localhost:11434/v1`
    style), optional session-only API key (never persisted by design), model picker
    populated from `/models`, temperature slider (0–2), system-prompt box.
  - Streaming chat via `POST /chat/completions` with server-sent events, delta-only
    rendering, and a working **Stop** button (`AbortController`).
  - Safe Markdown rendering (headings, bold/italic, lists, blockquotes, links, fenced
    code) — everything HTML-escaped before any tags are added; XSS-payload tests prove
    injection is neutralized.
  - System-prompt library: save/load/delete named prompts in `localStorage`.
  - Conversation persists in `localStorage`; **New chat** clears it.
  - **Export .md** produces a timestamped Markdown transcript with date/model/endpoint
    metadata, the system prompt as a blockquote, and `## You` / `## Assistant` turns
    (error and empty turns skipped).
- **`variants/`** — three themed builds generated by the palette-swap script:
  `daybreak.html` (light), `terminal.html` (green-on-black mono), `emberhall.html`
  (dark amber). Behavior is byte-for-byte the same core; only theme palette differs.
- **`scripts/build-variants.mjs`** — rebuilds variants from `index.html` using only
  Node's standard library (`npm run build:variants`).
- **`scripts/check-cors.mjs`** — optional diagnostic that probes an endpoint (default
  `http://localhost:11434/v1/models`) and reports whether the browser would
  actually be allowed to call it, with the exact `OLLAMA_ORIGINS` fix when not.
- **`tests/`** — 41 tests on Node's built-in runner covering config parsing, export
  formatting, the Markdown subset, and repo integrity (single-file guarantees,
  MIT license wording, README credit, no secrets, variants sharing one core).
- **`README.md`** — beginner-friendly docs crediting Asdale Dynamics, LLC; links to
  `The Massive AI Manual` hub.
- **`LICENSE`** — MIT, copyright line exactly `Copyright (c) 2026 Asdale Dynamics, LLC`.

## How to run it

- Use it: open `index.html` in a browser (Ollama running with `OLLAMA_ORIGINS="null"`),
  open Settings, press Refresh, pick a model, chat. Full walkthrough in README.md.
- Verify: `npm test` (Node 18+, no dependencies to install).
- Diagnose connectivity: `npm run check-cors` (or `node scripts/check-cors.mjs <base-url>`).
- Rebuild themes: `npm run build:variants`.

## Known gaps / notes

- The Markdown renderer covers a practical subset (no tables, nested lists, task lists,
  or footnotes). Intentional: it is escape-first and small on purpose.
- The conversation history is one localStorage list; no multi-session conversation
  manager, no rendering of images/tool calls.
- CORS "tested" here means: shipped diagnostic script + per-variant core tests +
  documented `OLLAMA_ORIGINS` steps. There is no live Ollama in CI-style test runs;
  `check-cors` verifies against whatever endpoint you point it at.
- API key is session-only by design; a browser reload clears it (that is the trade-off).
- Variants must be regenerated via `npm run build:variants` after palette edits; the
  test suite catches drift between variant cores and `index.html`.
